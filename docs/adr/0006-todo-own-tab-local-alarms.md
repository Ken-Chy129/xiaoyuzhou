# 待办单独一个 Tab，提醒用手机本地闹钟

待办、备忘、重点合成一个列表放在独立的「待办」Tab（资讯 / 待办 / Codex / 我），没有放进「我」：它是每天随手记、随时看的，而「我」里的储蓄一个月才看几次，多一层点击就会让人懒得记。录入用表单：右下角 ＋ 弹出底部表单，类型、日期、时间、重复、重点都是点选，标题可以语音输入，新建和编辑共用一套。曾先后试过手机端正则解析一句话、再改成服务端大模型解析加确认卡，但在 App 里「输入框 + 识别」看不出能设什么、精确设置要绕一圈，不如表单直接；自然语言录入以后交给个人 Agent（它也能建定时任务），服务端的 `/api/todos/parse` 先留着给它用。

到点提醒用手机本地的系统闹钟（AlarmManager）加通知，而不是服务器推送：只有一台手机，数据每次同步后在本地整体重排即可，不需要推送通道；代价是需要用户在小米上开通知、准点闹钟和自启动三项，App 在待办页顶部（缺项时）和「我 › 设置 › 待办提醒」二级页给出引导。重复事项完成时由服务端算下一次（31 号在小月取月末，过期很久的跳到今天之后的第一次）。

# 会话从各台机器本地读取，不经过 Mac 桌面端

本人用 Mac 上的 Codex 桌面端通过 SSH 连到各台机器干活，但会话实际跑在每台机器自己的常驻 Codex 后台服务里，Mac 只是一个显示和输入的窗口。所以「我」直接从每台机器本地的后台服务读取和推进会话，由该机器的 agentdeck 程序转发；这样 Mac 合盖、断网时手机照样能看到并推进会话，也不依赖 Mac 桌面端有没有开放接口。

补充（上线时确认）：Mac 本机的桌面端以 stdio 方式运行后台服务，没有 control socket，因此 Mac 本机上直接跑的会话暂不可见；如需要，可在 Mac 上常驻 `codex app-server daemon` 再接入。没有常驻后台服务的机器（如 sg1）relay 会持续重试，直到该机器启动 Codex。
